# Third Autonomous Growth Cycle

## Objective
Advance Parma Ads Agent toward verified incremental customers and commercial value while all external writes, merge/deploy, spend, tracking changes and the incorrect Wix account remain out of scope.

## Execution order

### P0 — evidence and commercial truth
1. Full keyword structural audit: all known keywords, ad-group overlap, match context, CPC distribution, structural cannibalization candidates. Conversion counts remain unverified evidence.
2. Search-term taxonomy: local/near-me, Kreuzberg/Wrangelkiez, quality, Italian, bio/sourdough, delivery/takeaway, open-now, generic and irrelevant candidates. Never negative local intent solely because registered conversions are zero.
3. Commercial value framework: direct order, reservation, marketplace order, repeat customer and walk-in proxy remain distinct. Unknown margin, order value and repeat rate are explicit inputs.
4. Wix ground-truth adapter interface prepared dormant; it must not call the currently incorrect account.

### P1 — acquisition intelligence
5. RSA proposal families: local intent, product/quality, direct-order. Structural evidence may justify copy proposals; unverified conversion evidence may not declare winners.
6. Ad-group consolidation simulations: quantify overlap but never equate overlap with proven waste.
7. Day/hour demand map from impressions, clicks, CTR and CPC; conversion timestamps excluded until integrity is verified.
8. Local/customer/query-value scores. Scores are decision-support priors, not observed business outcomes.
9. Local SEO implementation package: Pizza Kreuzberg, Bio Pizza Berlin/Kreuzberg, Sourdough Pizza Berlin, Wrangelkiez/Schlesisches Tor. Public factual claims only.
10. Competitor/review intelligence: distinguish public evidence, inference and recommendation.
11. Verified-USP library and DE/EN/IT message library. No invented certifications, ingredients, awards or operational claims.

### P1 — autonomous operating quality
12. Recommendation expiry and source-freshness contracts.
13. Conversion maturity/lag contract.
14. Human-gate batching: combine convenient independent approvals while preserving mandatory separate security/spend/write gates.
15. Weekly commercial review and customer-acquisition dashboard schemas.
16. Evidence-ranked optimization plan ordered by expected incremental-customer impact, evidence strength, reversibility and risk.

## Hard invariants
- Observation is not cause.
- Numerical similarity is not semantic identity.
- Prediction is not permission.
- Local-intent traffic can create unmeasured walk-ins.
- No budget increase while conversion integrity is unverified.
- No automatic negative keywords from zero registered bookings.
- No external write, campaign mutation, tracking mutation, spend, merge or deploy in this cycle.
- Wrong Wix account is excluded completely.
- If one task reaches an external/permission gate, continue the next GREEN task automatically.

## Completion rule
A task is DONE only with a durable artifact plus validation where code is involved. A task reaching a genuine access/write/deploy boundary becomes DONE_TO_BOUNDARY and must not stop unrelated GREEN work.
