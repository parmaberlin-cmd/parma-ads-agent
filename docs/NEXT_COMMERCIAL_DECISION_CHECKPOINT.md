# Next Commercial Decision Checkpoint

The first optimization experiment should not wait for perfect omniscience, but it must wait for the minimum evidence appropriate to the mutation.

## Experiment class A — RSA structural test, no budget increase
Minimum evidence:
- fresh asset inventory;
- query/message relevance evidence;
- landing continuity;
- policy-safe claims;
- stable campaign eligibility;
- independent write approval at execution time.
Conversion integrity is desirable for business-outcome evaluation, but structural preparation can proceed before it.

## Experiment class B — keyword/ad-group consolidation
Minimum evidence:
- complete fresh 29-keyword inventory;
- search-term routing evidence;
- match types and ad-group purpose;
- protected local-intent list;
- rollback mapping.
No keyword may be removed solely because registered conversions are zero.

## Experiment class C — budget increase
Minimum evidence:
- verified business outcome semantics;
- mature Ads/GA4/Wix reconciliation appropriate to the outcome;
- contribution-value inputs sufficient for break-even economics;
- marginal-response evidence;
- explicit spend approval.
Until then: blocked.

## Experiment class D — site/direct-order CTA
Minimum evidence:
- verified current direct-order path and availability;
- direct-order measurement contract implementation;
- mobile continuity baseline;
- current marketplace/direct economics if the change is justified economically;
- site-write approval.

## Current best no-spend path
1. Finish fresh keyword/search-term corpus ingestion when available.
2. Use local-intent and competitor evidence to refine RSA proposal.
3. Validate landing continuity and claims.
4. Package one reversible RSA structural experiment.
5. Keep budget unchanged.
6. Once conversion ground truth is repaired, evaluate customer outcome rather than proxy conversion volume.

This checkpoint never grants execution permission itself.
